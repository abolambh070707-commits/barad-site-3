# موقع مؤسسة براد لصيانة التكييف (Astro + Tailwind + Netlify)

موقع ثابت (HTML جاهز) وخفيف: لا مكتبات جافاسكربت، والدوال الخلفية للتقييمات فقط.

## أين أعدّل؟
| أريد تعديل | الملف |
|---|---|
| **عنوان الموقع (الدومين)** | `astro.config.mjs` (سطر `SITE_URL`) أو متغير `SITE_URL` في Netlify |
| رقم الهاتف (الأسطر phoneDisplay وphoneIntl وwhatsappUrl معاً)، ساعات العمل، اسم المنشأة، السجل التجاري، البريد | `src/data/siteData.ts` (قسم `siteConfig`) |
| الخدمات ونصوصها | `src/data/siteData.ts` (قسم `services`) |
| سعر البداية والأسئلة والماركات والإعلان والضمان والدفع | لوحة التحكم `/cms/` (ملفات `src/data/cms/*.json`) |
| شريط الثقة، خطوات العمل، أنواع المكيفات، روابط القائمة | `src/data/content.ts` |
| صور المعرض | `src/data/siteData.ts` (قسم `galleryItems`) |
| **ألوان الموقع** | `src/styles/global.css` (المتغيرات `--c-...`) |
| صفحة الضمان والخصوصية والشروط | `src/pages/warranty` و`privacy` و`terms` |
| **بطاقة الولاء والباقة السنوية** (نصوصها وشروطها) | `src/data/content.ts` (قسما `loyaltyCard` و`annualPackage`). وصفحتها `src/pages/loyalty` |
| صورة المشاركة (واتساب وغيره) | `public/images/og-default.jpg` (1200×630) |

خريطة الموقع و`robots.txt` وبيانات جوجل تُبنى تلقائياً من هذه الملفات.

## لوحة التحكم (Decap CMS)
- العنوان: `/cms/` (غير `/admin/` التي لمراجعة التقييمات).
- تعدّل من خلالها: مدة الضمان، طرق الدفع، أسعار «يبدأ من»، شريط الإعلان، الأسئلة الشائعة، الماركات.
- كل حفظ يُرسَل إلى GitHub كتعديل على ملفات `src/data/cms/*.json` ثم يُعاد بناء الموقع تلقائياً خلال دقيقة أو دقيقتين.
- الإعداد في `public/cms/config.yml` (غيّر `repo` إلى مستودعك). يلزم GitHub OAuth App ومزوّد GitHub في Netlify.
- إن حدث تعديل خاطئ: افتح المستودع على GitHub وارجع إلى التعديل السابق.

## هيكل الكود
- `src/components/`: مكونات صغيرة قابلة لإعادة الاستخدام (`CtaButtons`، `Faq`، `Icon`...). أي زر اتصال/واتساب جديد يستخدم `CtaButtons`.
- `src/lib/schema.ts`: بيانات جوجل المنظمة (النشاط، الخدمة، الأسئلة).
- `src/lib/assets.ts`: يضيف بصمة لملفات `public/js` تلقائياً فيتحدّث الكاش عند أي تعديل.
- `public/js/`: جافاسكربت الواجهة (بسيط وبلا مكتبات).
- `netlify/functions/`: التقييمات ولوحة الإدارة.
- الألوان في القوالب «أدوار» (`bg-brand`، `text-ink`، `bg-card`...) وليست أرقاماً، لتغيير الهوية عدّل `global.css` فقط.

## إضافة خدمة أو سؤال
انسخ عنصراً من القائمة في الملف المناسب (انظر الجدول) وغيّر نصه. تُنشأ الصفحة وتدخل الخريطة والقوائم تلقائياً.

## ملاحظات
- النشاط خدمة متنقلة بلا محل: لا يُعرض عنوان شارع في الموقع ولا في بيانات جوجل، والنص في `siteConfig.locationNote`.
- صفحات الأحياء والمناطق أُلغيت، والموقع يذكر «نخدم جميع أحياء جدة». أي رابط قديم لها يُحوَّل للرئيسية عبر `public/_redirects`.

## التقييمات (متغيرات البيئة في Netlify)
Site configuration ← Environment variables:

- `ADMIN_PASSWORD`: كلمة مرور `/admin/` (8 أحرف فأكثر، يُفضَّل 16+). تغييرها يُنهي كل الجلسات الحالية.
- `SITE_URL` (اختياري): عنوان الموقع النهائي إن لم تعدّله في `astro.config.mjs`.

بعد إضافتها اعمل Deploy جديد.

## خط عربي (اختياري)
الموقع يستخدم خطوط النظام (أخف ما يمكن). لإضافة خط مستضاف: ضع ملف `woff2` (مثل IBM Plex Sans Arabic أو Tajawal) في `public/fonts/`، ثم أضف في `global.css`:
`@font-face { font-family: 'Brand'; src: url('/fonts/brand.woff2') format('woff2'); font-display: swap; }`
وضع `'Brand'` أول `--font-sans`. سياسة CSP تسمح بالخطوط المحلية.

## التشغيل محلياً
`npm install` ثم `npm run dev`. لتجربة الدوال استخدم `npx netlify dev`.
بعد أول `npm install` احتفظ بملف `package-lock.json` الناتج وارفعه مع المشروع ليكون البناء مطابقاً في كل مرة.
